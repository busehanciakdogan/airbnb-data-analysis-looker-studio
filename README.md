# Airbnb Data Analysis | Looker Studio

## Project Overview

This project presents an Airbnb data analysis dashboard developed using Google Looker Studio.

The analysis focuses on listing performance, occupancy rates, pricing trends, room types, and guest review scores. The dashboard transforms the data into key performance indicators and visual analyses to support data-driven business insights.

## Dashboard

The dashboard includes the following key performance indicators:

- Occupancy Rate: 75.68%
- Average Price: 158.02
- Average Review Score: 4.67

## Analysis

### Room Type Analysis

The relationship between room type, price, and occupancy rate was analyzed.

The analysis shows that lower-priced room types have higher occupancy rates. The dashboard compares Private Room, Entire Home/Apt, and Shared Room categories in terms of average price and occupancy rate.

### Review Score Analysis

Guest review scores were analyzed over time according to listing availability.

The analysis indicates that availability status did not have a significant effect on review scores during the analyzed period.

### Price Trend Analysis

Monthly price changes were examined between September 2022 and January 2023.

The analysis shows that the lowest average price occurred in November, followed by an increase toward the end of the period.

### Price Range & Occupancy Analysis

Occupancy rates and review scores were compared across different price ranges.

| Price Range | Occupancy Rate | Review Score |
|---|---:|---:|
| Under 100 | 82.22% | 4.68 |
| 100-149 | 74.90% | 4.69 |
| 150-199 | 71.56% | 4.62 |
| 200-299 | 70.03% | 4.64 |
| 300+ | 65.68% | 4.65 |

The analysis shows a 16.54 percentage-point difference in occupancy between the lowest and highest price ranges, while review scores remain relatively close across the groups.

## Key Findings

- Lower-priced listings have higher occupancy rates.
- Higher prices do not appear to negatively affect guest review scores in the analyzed data.
- The difference in guest review scores between price ranges is relatively small.
- Higher-priced listings have lower occupancy rates compared with lower-priced listings.

## Business Recommendation

The analysis suggests using pre-season campaigns to increase the occupancy of higher-priced listings.
